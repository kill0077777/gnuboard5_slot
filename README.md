# 그누보드5 인디 슬롯 이식본

`plugin/slot/`을 그누보드5 사이트의 `plugin/slot/` 경로에 올려 사용하는 플러그인입니다. 이미지 폴더는 원본 ZIP의 `images/`를 파일 내용 변경 없이 그대로 복사했습니다. 원본 ZIP도 `legacy-source/slot.zip`에 함께 보관했습니다.

## 설치

1. 사이트 파일을 백업합니다.
2. 이 패키지의 `plugin/slot/` 폴더를 그누보드5 루트의 `plugin/slot/`에 업로드합니다.
3. DB 백업 후 `plugin/slot/install.sql`을 실행합니다. 기본 DB 접두사가 `g5_`가 아니면 SQL의 `g5_slot_member`를 실제 접두사에 맞춰 바꿉니다.
4. 로그인한 뒤 `https://사이트주소/plugin/slot/`을 엽니다. 그누보드 테마의 공통 헤더·푸터를 사용합니다.

첫 접속 시 회원별 게임 포인트 10,000P가 생성됩니다. 해당 값은 그누보드의 실제 회원 포인트와 별도이며, 기본적으로 환전하거나 현금 가치가 없습니다.

## 기존 데이터 이전

기존 제로보드 DB의 `zetyx_member_table.gamepoint`를 그누보드 회원으로 이전할 때는 회원 ID가 정확히 대응하는지 먼저 확인하고, 별도 DB 백업 후 관리자 또는 DB 담당자가 다음 형태로 대상 레코드를 적재해야 합니다. 아래 예시의 `OLD_DB`는 실제 기존 DB명으로 바꾸고, 회원 ID 매칭 및 문자셋을 검증하십시오.

```sql
INSERT INTO g5_slot_member (mb_id, balance)
SELECT m.mb_id, GREATEST(0, CAST(o.gamepoint AS SIGNED))
FROM g5_member AS m
JOIN OLD_DB.zetyx_member_table AS o ON o.user_id = m.mb_id
ON DUPLICATE KEY UPDATE balance = VALUES(balance);
```

사이트의 테이블 접두사, 기존 DB 연결 방식, ID 길이/인코딩에 따라 쿼리를 조정해야 합니다. 이식본은 원본 회원 테이블을 직접 수정하지 않습니다.

## 이식 범위와 주의사항

원본은 제로보드4의 `zetyx_member_table`, `mysql_*` 함수, IE 전용 이벤트 처리와 Flash(SWF)에 의존해 그누보드5 및 현재 브라우저에서 그대로 실행되지 않습니다. 이식본은 그누보드5 로그인 연동, 별도 게임 포인트 테이블, CSRF 검증과 트랜잭션 기반 차감/지급을 포함하며, 원본 슬롯 GIF/배경 이미지를 재사용합니다. 슬롯 추첨 로직은 PHP의 안전한 난수 생성으로 새로 구현했고, 지급 규칙은 세 가로줄에서 동일 기호 3개 일치 시 배팅액에 기호별 배수를 곱하는 방식입니다.

Flash 기반 음향·잭팟 연출, 자동 플레이, 홀드/보너스/서비스 게임 및 원본의 랭킹·통계 체계는 이식하지 않았습니다. SWF 파일은 원본 백업 안에 남아 있지만 현재 브라우저에서 재생되지 않습니다. 기존 동작을 1:1로 복원해야 하거나 포인트가 실제 가치와 연결된다면, 운영 전 지급 확률·보상 규칙을 별도 검토하고 필요한 기능을 추가해야 합니다. 결제·환전 또는 현금성 보상은 포함되어 있지 않습니다.

## 빠른 점검

- PHP 7.4 이상 및 그누보드5 설치 환경을 권장합니다.
- DB 계정에 `g5_slot_member` 생성 및 갱신 권한이 필요합니다.
- 페이지는 그누보드5 `common.php`, `head.php`, `tail.php`를 사용하므로 반드시 `plugin/slot/` 경로에 설치해야 합니다.
- 운영 서버에 반영하기 전 테스트 계정으로 로그인, 잔액 차감, 당첨 지급, 새로고침 및 동시 요청을 점검하십시오.
